# AI 노트 규칙

AI는 Claude Code가 레포 안에서 스킬(`.claude/skills/`)을 따라 일하는 방식으로만 쓴다. API 키는 없다.

## 사실

1. 숫자는 `public/data/cards/latest.json`과 `public/data/prices/`에서만 가져온다. 계산이 필요하면 스크립트로 계산하고 손으로 짐작하지 않는다.
2. 뉴스·공시·실적 같은 바깥 사실은 웹에서 찾고 `sources`에 URL을 단다. 출처가 없는 바깥 사실은 쓰지 않는다.
3. 출처가 하나뿐이거나 서로 어긋나면 "확인되지 않음"이라고 쓰거나 뺀다.
4. 모르는 것은 모른다고 쓴다.

## 말투와 내용

- 한국어, 짧게. 매일 노트는 종목당 3–5문장.
- **권유하지 않는다.** "사라/팔아라" 대신 "이 시나리오에서 볼 신호는 …"처럼 판단 재료를 쓴다.
- 오를 이유와 내릴 이유를 함께 쓴다. 한쪽만 쓰지 않는다.
- 유사 패턴은 언제나 기저율과 함께 말한다. 표본 수를 밝힌다.
- 자신의 지난 예측 성적이 나쁘면 그것도 쓴다.

## 예측

- AI 예측은 `docs/04` 형식으로 노트의 `forecasts`에 넣는다.
- 확률은 0.35–0.65 사이가 보통이다. 그 밖으로 나가려면 이유가 분명해야 한다.
- 이미 기한이 남은 같은 종목의 AI 예측이 있으면 새로 만들지 않는다(종목당 동시에 하나).

## 블라인드 리플레이 해설 (스포일러 금지)

- 단계별 해설은 `scripts/replay-window`가 넘겨주는 **그 단계까지의 데이터만** 보고 쓴다. 종목명·날짜를 알아도 해설에 쓰지 않는다.
- 미래를 암시하는 표현("곧", "이후 급등" 등)을 쓰지 않는다. `npm run check:replays`가 잡는다.
- 공개 후 회고(`reveal`)에서만 실제 사건과 출처를 쓴다.

## 토큰 절약

- 원본 일봉 파일을 통째로 읽지 않는다. 카드를 읽는다.
- `changed: false`인 종목(플래그가 없고 일간 변동이 ATR보다 작음)은 한 줄로 끝낸다.
- 웹 조사는 하루 최대 3종목, 플래그가 있는 종목만.
- 노트 빈도는 `config/settings.json`의 `ai.cadence`(`daily | tue-thu | weekly`)를 따른다.
