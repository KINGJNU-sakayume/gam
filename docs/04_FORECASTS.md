# 예측과 채점

나와 AI는 같은 형식으로 예측하고 같은 규칙으로 채점된다.

## 형식

```json
{ "id": "f-…", "by": "me | ai", "ticker": "US:NVDA",
  "madeAfter": "2026-10-16", "horizon": 20,
  "pUp": 0.6, "low": -0.08, "high": 0.12, "why": "한 줄 이유" }
```

- `madeAfter`: 예측할 때 본 데이터의 마지막 날짜. 이 날 종가가 기준가다.
- `horizon`: 거래일 수. 기본 20.
- `pUp`: 기준가보다 `horizon` 거래일 뒤 종가가 **높을** 확률(0.05–0.95).
- `low`, `high`: 그 수익률이 들어갈 것이라 보는 **80% 구간**.

## 채점 (기한이 된 예측만)

- **방향 점수(Brier)**: `(pUp − 결과)²`, 결과는 상승 1·그 외 0. 낮을수록 좋다. 0.25는 늘 50%라고 말한 것과 같다.
- **구간 적중**: 실제 수익률이 `[low, high]` 안에 들었는가. 80% 구간이므로 장기적으로 약 80%가 들어야 정직한 구간이다.
- **보정표**: `pUp`을 0.1 단위로 묶어 "말한 확률 vs 실제 상승 비율"을 본다.
- 수익률은 수정 가격(`가격 × f`)으로 계산한다.

나와 AI의 점수는 같은 표에 나란히 보여준다. 기간이 같은 예측끼리만 비교하는 "맞대결" 표도 함께 본다.
