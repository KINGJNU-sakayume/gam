# gam — 비전

**gam(감)**은 한 사람이 스윙 매매의 감을 익히기 위한 개인 모의투자 사이트다. 실제 돈과 실제 주문은 없다.

## 지키는 것

1. **혼자 쓰는 도구.** 계정, 서버, DB가 없다. GitHub Pages(정적 사이트) + GitHub Actions(데이터) + Claude Code 예약 작업(AI 노트)이 전부다.
2. **스윙 전용.** 일봉만 쓴다. 장중 실시간 시세는 범위 밖이다.
3. **판단은 내가 한다.** 사이트와 AI는 재료와 기록과 채점을 준다. 노트는 투자 권유가 아니며 화면에 그렇게 표시한다.
4. **모든 예측은 채점된다.** 나의 예측과 AI의 예측은 같은 형식으로 남고, 기한이 지나면 같은 규칙으로 채점된다. 성적이 나빠도 숨기지 않는다.
5. **기록에서 다시 계산한다.** 체결, 잔고, 손익, 예측 성적은 저장하지 않고 주문·예측 기록과 시세에서 매번 계산한다(`docs/03`).
6. **AI는 사실을 지어내지 않는다.** AI 노트의 사실은 `public/data/`의 숫자나 출처 URL이 있는 조사에서만 온다(`docs/05`).
7. **API 결제 없음.** AI는 Claude 구독 안의 Claude Code가 레포에서 일한다. 사이트 안에서 AI를 부르지 않는다.

## 구성

| 영역 | 무엇 | 어디 |
|---|---|---|
| 시장 지도 | 한·미 대표 지수, 원/달러 | `config/watchlist.json`의 `indices` |
| 관심 종목 | 내가 고른 종목(+ 나중에 주간 후보) | `config/watchlist.json`의 `stocks` |
| 스크리닝 유니버스 | 코스피200, 코스닥150, S&P 500, 나스닥100 | M2 |
| 모의 매매 | 일봉 기반 체결, 수수료·세금·호가 단위 | `src/engine/` |
| 블라인드 리플레이 | 이름·날짜를 가린 과거 차트로 연습 | `src/replay/` |
| 예측 | 나와 AI의 20거래일 예측, 자동 채점 | `src/engine/forecast.ts` |
| AI 노트 | 매일 노트, 주간 리뷰, 리플레이 해설 | `.claude/skills/`, `public/data/notes/` |

## 단계

- **M1**: 데이터 수집, 차트, 모의 매매, 예측과 채점, 블라인드 리플레이, 기록 내보내기, AI 매일 노트
- **M2**: 스크리닝 유니버스와 주간 후보, 주간 리뷰
- **M3**: 공시(OpenDART)·뉴스 타임라인을 수집 단계로 옮기기(키 발급 후)
- **M4**: 한국투자증권 API로 시세 출처 교체(계좌 개설 후)
